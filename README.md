# forgeglob

Forge list/glob set operations for shell-friendly data wrangling.

**Site:** https://theworker02.github.io/forgeglob/

## Install / run

```bash
git clone https://github.com/theworker02/forgeglob.git
cd forgeglob
node src/cli.js
node --test
```
